# OnTEPT
OnTEPT es una ontología OWL multimodal para identificar y clasificar el TEPT. Integra criterios DSM-5 y CIE-11, pruebas psicométricas (CAPS-5, PCL-5, PC-PTSD-5), datos EEG con más de 20 características y razonamiento automático. Define cuatro fenotipos y permite interoperabilidad asimétrica. Es bilingüe (español/inglés).
