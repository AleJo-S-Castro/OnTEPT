# Versiones anteriores de OnTEPT

Este directorio almacena versiones anteriores de la ontología para trazabilidad del proceso de desarrollo. **No se recomienda usar estas versiones para nuevas aplicaciones;** usar siempre la versión en `../current/`.

## Historial

| Versión | Archivo | Estado | Notas principales |
|---|---|---|---|
| Pre-release | `onTEPT_v2.9.rdf` | Archivada | Primera versión con criterios DSM-5 completos |
| Pre-release | `onTEPT_v2.10.rdf` | Archivada | Añade criterios CIE-11 básicos |
| Pre-release | `onTEPT_v2.11.rdf` | Archivada | TEPT complejo CIE-11; subclases DSO |
| Pre-release | `onTEPT_v2.12.rdf` | Archivada | Corrección asimetría CIE-11; PCL5Property |
| **1.0 (v2.13)** | `../current/onTEPT_v1.0.rdf` | **Estable** | Primera versión pública |

Los cambios entre versiones se describen en detalle en [`../../CHANGELOG.md`](../../CHANGELOG.md).

## Convención de nombres para versiones futuras

Las versiones futuras se nombrarán como `onTEPT_v{MAJOR}.{MINOR}.rdf` y se colocarán aquí al publicar una nueva versión estable en `current/`.
